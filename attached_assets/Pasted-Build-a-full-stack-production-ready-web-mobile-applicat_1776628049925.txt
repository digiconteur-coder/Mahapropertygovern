Build a full-stack, production-ready web + mobile application called "Bharat Property Card System" with multi-role architecture.

This is NOT a marketplace. It is a national property execution system similar to DigiLocker + Banking apps.

Use the following stack:
- Frontend: Next.js (React), Tailwind CSS
- Backend: Node.js with Express OR NestJS
- Database: PostgreSQL (use Prisma ORM)
- Auth: JWT + OTP-based login (simulate Aadhaar/PAN login)
- Cloud-ready architecture (modular services)
- Follow RBAC (Role-Based Access Control)

-------------------------------------
🔐 CORE ROLES (VERY IMPORTANT)
-------------------------------------

1. CITIZEN (Property Owner)
2. CPF (Broker / Facilitator)
3. DEVELOPER (Builder)
4. GOVERNMENT OFFICER (Registrar / Talathi / Authority)
5. BANK (Financial Institution)

Each role must have separate dashboards, APIs, and permissions.

-------------------------------------
🧠 CORE SYSTEM ARCHITECTURE
-------------------------------------

Create a central "RERAW Core Engine" that handles:

- Property ownership logic
- Transaction workflows
- Approval pipelines
- Audit logs
- AI verification simulation
- Secure ledger (simulate blockchain-like logging)
